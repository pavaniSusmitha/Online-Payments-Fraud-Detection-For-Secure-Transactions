Online payment systems are vulnerable to fraudulent transactions, which can result in significant financial losses. This project aims to build an effective machine learning-based fraud detection system that identifies suspicious transactions in real-time, ensuring safe and secure digital transactions.

Features
Fraud Detection Engine
Uses machine learning models to identify fraudulent transactions in real-time.

Exploratory Data Analysis (EDA)
Visual insights into transaction types, amounts, and fraud distribution.

Multiple ML Models
Includes Random Forest, XGBoost, SVM, and others with hyperparameter tuning.

Web Interface
Simple and user-friendly UI built with HTML and CSS to input transaction details.

Model Deployment
Flask-based backend to serve the trained model and handle predictions.

Performance Evaluation
Generates accuracy, precision, recall, F1-score, and confusion matrix reports.

Clean Project Structure
Modular code with separation of concerns (notebook, model, UI, backend).

Customizable and Extendable
Easily integrate with real-time transaction systems or other dashboards.

Tech Stack
Frontend: HTML, CSS

Backend: Python (Flask)

Data Analysis & ML: Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn

Model Deployment: Flask API

Version Control: Git & GitHub
